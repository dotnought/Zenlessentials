# Code of Conduct

Zenlessentials welcomes contributions from people of all backgrounds and experience levels. This code applies to issues, pull requests, reviews, and other project discussions.

## Community standards

- Treat other contributors with respect and assume good faith.
- Give specific, constructive feedback about the work.
- Respect other people's privacy and ask permission before sharing their information.
- Keep project spaces free of harassment, discrimination, threats, personal attacks, and spam.

## Reporting and enforcement

Use GitHub's **Report content** action on the relevant post or comment and include the context privately. Where GitHub offers a choice, you can send the report to repository maintainers or GitHub Support. [GitHub reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

Maintainers may remove content, limit participation, or block accounts when needed to protect the community. They will consider the context and severity of the conduct and handle reports discreetly.
